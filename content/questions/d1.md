# Domain 1 — Agents and Workflows

### d1-arch-01
skill: 1.1
type: single
A team must extract the same five fields (vendor, invoice number, date, currency, total) from 20,000 scanned invoices. Every document is processed the same way, and the output feeds an accounting system. Which architecture is most appropriate?
- [ ] An autonomous agent with file-reading tools that decides for each invoice which pages to read and which fields to extract
- [x] One Claude call per document with a fixed prompt and a JSON output schema, submitted as an asynchronous batch job
- [ ] An orchestrator agent that spawns one worker subagent per field so each field gets a dedicated, focused context
- [ ] An evaluator-optimizer loop in which a grader model reviews every extraction and requests revisions until it approves
> The steps are fully known and identical for every document, so the simplest tier — a single, well-prompted call with structured output — is correct; running it as a batch also cuts cost. An agent adds latency, cost and nondeterminism with no benefit. Spawning workers per field multiplies tokens for a task one call handles. An evaluator loop on every document is unnecessary unless measured accuracy demands it.

### d1-arch-02
skill: 1.1
type: single
A research assistant must answer questions such as "compare the pricing, compliance certifications and SLAs of the top cloud vector databases". The number of sources and sub-questions differs widely between requests. Which workflow pattern best fits?
- [ ] Prompt chaining with a fixed sequence of search, summarize and compare calls, each gated by a format check
- [ ] Routing, where a classifier sends each question to one of several specialized research prompts
- [x] Orchestrator-workers: a lead model decides the subtasks at runtime and delegates them to workers
- [ ] Parallelization by voting, where five instances answer the full question and the majority answer wins
> When subtasks cannot be predicted in advance and depend on the input, the orchestrator-workers pattern fits: the orchestrator decomposes dynamically and synthesizes the workers' results. Prompt chaining and routing assume a fixed structure. Voting runs the same task several times for consensus; it doesn't break down a broad research question.

- [x] An agent's LLM directs its own process and tool use; a workflow follows predefined code paths

- [x] Subagents start with a fresh context; the supervisor must pass the relevant facts in the delegation prompt

# Domain 3 — Claude Code Configuration & Workflows

### a3-md-01
skill: 3.1
scenario: S2
A new team member reports that Claude Code doesn't follow the team's API naming conventions, while it does for everyone else. The conventions were added months ago by the tech lead. Where are they most likely stored?
- [ ] In the project's `CLAUDE.md`, which new clones only load after the first commit by that developer
- [x] In the tech lead's `~/.claude/CLAUDE.md`, which is personal and not shared through version control
- [ ] In a `.claude/rules/` file, which requires each developer to activate it with a command first
- [ ] In the repository's README, which Claude Code reads only when it is explicitly mentioned in a prompt
> User-level memory applies only to that user. Team conventions belong in the project CLAUDE.md (or `.claude/rules/`), committed to the repository. Project files load for every clone, and rules don't need activation.
